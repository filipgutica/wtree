wtree

Which worktrees are still in use, and which can go.

wtree adds age, pull request state, and safe cleanup to git worktree list. You review the plan before anything is removed.

$ brew install filipgutica/tap/wtree

Homebrew installs Node.js. GitHub CLI (gh) is optional for pull request state, and fzf is optional for wtree go. New to Homebrew? Install it first.

On screen

[-]
Blocked. The status line says why.
M @
M is the main worktree. @ is the one you are in.
* ↑
Uncommitted changes, or commits not pushed yet.
✓
Merged into the default branch. Squash and rebase merges do not show it, so trust the PR column.
PR
open, merged, closed, or - for none. ? means GitHub state is unavailable.
·
The path is the default, ~/.wtree/<repo>/<branch>.

Commands

The list is for the repository you are in. Cleanup asks before it removes anything.

  • wtree

    List worktrees, oldest first after the main one.

  • wtree ui

    Browse, filter, select, and remove worktrees.

  • wtree clean --done --dry-run

    Preview removing worktrees whose pull request is merged or closed.

  • wtree new feat/example

    Create a worktree for a branch, or print the existing path.

  • wtree go

    Pick a worktree or branch and print its path.

  • wtree --size

    Measure disk usage with du. It is off by default.

  • wtree --json

    Read the list as JSON.

Keys in wtree ui

Press ? in the app for the full list.

  • Space

    Select a worktree. Blocked ones refuse and say why.

  • Enter

    Show the full branch and path.

  • /

    Filter by branch or path.

  • d

    Review removal of the selection, then confirm.

  • o

    Exit and print the focused worktree's path.

  • n

    Create a worktree for a branch.

Change directory

A program cannot change its parent shell's directory, so wtree ships a small wrapper.

  • eval "$(wtree shell-init zsh)"

    Add this to ~/.zshrc. Use bash for ~/.bashrc.

  • wt go

    Pick a worktree, then change into it. wt new, wt path, and wt ui work the same way.

Good to know

Cleanup asks first. It prints the plan and waits for your confirmation. --yes skips the prompt, and --dry-run never removes. Branches are deleted only with --delete-branch.

Blocked worktrees stay put. Main and current worktrees are never removed. Dirty, unpushed, and locked ones need --force.

Unknown pull request state stops a filtered cleanup. If gh is missing, signed out, or offline, wtree clean --done exits with an error and does not report an empty result.

Scripts and agents never hang. Without a terminal, clean, rm, and prune print the plan and exit with code 2 unless you pass --dry-run or --yes. wtree ui also exits with code 2.
